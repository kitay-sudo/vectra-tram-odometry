# JS-порт ядра и связки (оценщик песочницы)

`est.js` повторяет `estimator_core.py` пакета: ядро `684530832766` (коммит `3466ac4`, со срывом
обеих тележек разом и оценкой шума показаний). `runner.js` повторяет ту часть `Runner`
(`runner.py`), которую видит ядро. Песочница считает оценку этими файлами с листом жюри
`config/tram.yaml`: [simulator/README.md](../simulator/README.md),
[docs/SANDBOX.md](../docs/SANDBOX.md).

**Разделы:**

- [1. Файлы](#1-файлы)

Команды выполняются из корня репозитория в bash (Linux, macOS, Git Bash). `<repo>` - полный
путь к клону.

## 1. Файлы

| Файл | Что это |
|---|---|
| `est.js` | перенос `estimator_core.py`, список функций в заголовке файла |
| `runner.js` | перенос шага `Runner` и база «только колесо» |
| `gen_sheet.py` | лист песочницы `simulator/js/sheet.js` из листа пакета |
| `sync.js` | копии `est.js`, `runner.js` в `simulator/js/` байт в байт |
| `record.py`, `compare.js` | сверка ядра на 15 сценариях |
| `record_bag.py`, `compare_bag.js` | сверка ядра на реальной записи с отказами |
| `record_runner.py`, `compare_runner.js` | сверка связки на тех же сообщениях |
| `gnss_check.py` | проверка, что GNSS после выставки не меняет скорость и путь |
| `check.sh` | всё вместе одной командой |

- **Что перенесено в `runner.js`.** Сетка по меткам (узлы кратны dt), свежесть показаний по
  тележкам, `wheel_timeout` (разомкнутый режим), `handle_timeout`, приведение показания к
  моменту шага, ускорение выхода, σ пути (`position_sigma`) и база «только колесо»
  (`NaiveCore` из `tools/eval_replay.py`).
- **Что не перенесено.** Своя база времени связки (сбросы, провалы, очередь) и положение.
  Сверка проверяет, что на записи эти ветки не сработали.
- **Сверка на 15 сценариях.** `prototype/scenarios.py`, Params по умолчанию: 4 оси × 2
  датчика, рад/с.
- **Сверка на записи.** Лист жюри (2 тележки, км/ч, табличный привод, 20 Гц), входы
  `core.step` так, как их подаёт `Runner`. Варианты с аномалиями из `tools/inject.py` и формы
  срыва из `tools/slip_study.py` (EDGE). Кроме чисел совпадают режим, неоднозначность, срыв и
  срыв всех осей.
- **Лист песочницы.** `gen_sheet.py` читает лист так же, как нода
  (`tools/export_replay.resolve_sheet`), и переносит нужные песочнице параметры ноды:
  таймауты, окно выставки, `speed_output_delay_s`.

## 2. Сверка

Python работает в образе пакета `vectra/tram:compose` с кодом пакета из дерева, Node - на
хосте или в `vectra/tram:sim`. Время прогона: замера нет.

Сверить перенос с пакетом (код выхода 0 - совпадает).

```bash
bash js-port/check.sh
```

|---|---|
| `IMAGE` | образ с Python и numpy, по умолчанию `vectra/tram:compose` |
| `DATA_DIR` | папка записей, по умолчанию `<repo>/data` |
| `CACHE_DIR` | кэш записей, по умолчанию `<repo>/analysis/cache` |
| `BAG` | запись для сверки, по умолчанию `30618_e9a34502` |
| `QUICK=1` | только чистый вариант записи |
| `EDGEV` | формы срыва для сверки ядра, по умолчанию шесть видов |

## 3. Отпечаток ядра

`TramEst.PORT` в `est.js` указывает ядро, с которым порт сверен: `core_sha1` - это sha1
`estimator_core.py` с переводами строк LF, 12 знаков. Тот же отпечаток пишут
`tools/export_replay.py` (в `simulator/replays/index.js`), `gen_sheet.py` (в
`simulator/js/sheet.js`), `simulator/tools/gen_record.py` и `record*.py`. Если прогоны
комиссии или лист посчитаны другим ядром, страница сама подписывает песочницу «упрощённое
ядро» и убирает утверждение о совпадении. `compare*.js` при другом отпечатке завершаются с
кодом 1.

Для песочницы в `est.js` есть `Estimator.diag()` (в ядре его нет): запись решения фильтра по
каждой оси (принята, по согласию, буксование, юз, скачок, после срыва, «стоим или
скользим», выброс) и причины исключения датчика. Запись только читает состояние и на числа
не влияет: `compare.js` и `compare_bag.js` сверяют порт без записи, `compare_runner.js` - с
записью, как в песочнице.

## 4. Если ядро поменялось

Сначала перенести правку в `est.js`: затронутые места - по списку «ЗЕРКАЛО» в заголовке
файла. Правку в шаге `Runner` перенести в `runner.js`.

Сверить перенос с пакетом. Если сверка зелёная, а сменился только отпечаток, обновить
`PORT` в `est.js`.

```bash
bash js-port/check.sh
```

Скопировать перенос в песочницу.

```bash
node js-port/sync.js
```

Пересобрать лист песочницы, если менялся лист пакета.

```bash
docker run --rm -v <repo>:/repo -w /repo vectra/tram:compose python3 js-port/gen_sheet.py
```

Пересчитать сценарии и записать сводку в `docs/SANDBOX.md`, затем проверить страницу
([simulator/README.md, раздел 7](../simulator/README.md#7-проверки)).

```bash
node simulator/test/sandbox_report.js --write
```
