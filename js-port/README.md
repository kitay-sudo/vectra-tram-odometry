# JS-порт оценщика и имитатора

- `est.js` — порт `estimator_core.py` один к одному (UKF, проверка правдоподобия, адаптация, стоянка).
- `plant.js` — порт `plant.py`. Добавлено для демо: противобуксовочная и противоюзная защита
  (`protect = true`), масса `M` и общий масштаб колёс `wheel_scale` как изменяемые поля.
  Без защиты моторное колесо на льду раскручивается до сотен км/ч, а под ЭД-торможением крутится назад.
- `record.py` — пишет входы и выходы Python-оценщика по всем 15 сценариям в `rec.json`.
- `compare.js` — прогоняет JS-порт на тех же входах и сравнивает.

Проверка: `python3 record.py && node compare.js`.
Результат: расхождение скорости не больше 6·10⁻¹³ м/с, пути 3·10⁻¹¹ м, режимы совпадают на всех 80 000 шагах;
шаг JS-порта 35–50 мкс против 1,14 мс в Python.
